## 15. 版本事实来源

```text
V1.0 真实项目运行与演进历史
        ↓
V1.1–V1.4 专项能力 / Contract / Rule
        ↓
V2.0 AI_NATIVE_PROJECT_OS_V2.0.md
        ↓
V2.0 Execution Baseline / Runtime Contracts
        ↓
API / SDK Contract 实现
```

发生规则冲突时：
1. V2.0 定义能力边界和通用抽象；
2. 已存在的专项 Contract 继续承担其具体执行约束；
3. 若专项 Contract 与 V2.0 基础抽象冲突，应升级专项 Contract，而不是在项目中形成第三套规则；
4. Runtime 只负责编排，不复制专业执行规则。
